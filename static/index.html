How RAG Works

This pipeline implements a complete Retrieval-Augmented Generation architecture. Documents undergo intelligent ingestion via OCR and Docling to produce structured Markdown. The MarkdownHeaderTextSplitter performs semantic chunking preserving hierarchy. Each chunk is vectorized using embedding models and stored in ChromaDB. At query time, the system retrieves top-K matches, re-ranks results, and generates contextual responses with page-level citations grounded in your actual documents.

Supported formats: PDF, PNG, JPG, WEBP
